# 源码与构建

以下命令用于在电脑 WSL 中重新编译适配组件。

## 代码位置

| 路径 | 内容 |

| `code/port/patches/nabu-display-runtime.patch` | 显示释放栅栏与电源控制 |
| `code/port/sensor-hal.c`、`sensor-vdi.cpp`、`ssc-client.c` | SSC 传感器和 HDI 桥接 |
| `code/port/motion-service.cpp` | 真实重力到 OHOS 旋转事件 |

## 建立 WSL 编译目录

准备自己的本地输入：

- 与镜像版本匹配的 Linux OHOS Clang 归档。
- 自己 SDK 的 native `sysroot`。
- 本地原始 `system.img`，用于提取链接所需系统库。

在专用 WSL 环境中使用以下固定目录，避免和其他工程混用：

```text
/root/nabu-package       本包 code 的副本
/root/nabu-build         内核、工具链、依赖与编译产物
/root/nabu-rootfs        从自己的镜像提取的链接库
```

安装编译工具时沿用安装文档中的 7897 代理环境：

```bash
sudo -E apt-get install -y build-essential gcc-aarch64-linux-gnu g++-aarch64-linux-gnu \
  make cmake ninja-build meson python3-mako python3-packaging flex bison bc \
  libssl-dev libelf-dev device-tree-compiler cpio xz-utils bzip2 pkg-config
```

初始化命令（路径按自己的电脑调整）：

```bash
sudo bash /mnt/d/nabu-ohos-patchkit/scripts/bootstrap-build.sh \
  /mnt/d/nabu-ohos-patchkit \
  /mnt/d/my-sdk/system-image-tablet-arm64/system.img \
  /mnt/d/my-sdk/native/sysroot \
  /mnt/d/my-sdk/ohos-clang-linux.tar.gz
```

脚本从本地 SDK 输入提取头文件和链接库。

## 构建命令

```bash
cd /root/nabu-package

# 内核使用已保存的完整配置，兼容补丁在初始化阶段应用
cd /root/nabu-build/linux-6.17
make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j8 Image modules
cp arch/arm64/boot/Image /root/nabu-package/port/out/Image-nabu-ohos
cd /root/nabu-package
bash tools/build_ashmem.sh
bash tools/build_fastrpc.sh

# libdrm、Mesa、显示 HDI
bash tools/build_libdrm.sh
python3 tools/prepare_mesa.py
bash tools/build_mesa.sh
python3 tools/build_display.py

# 传感器、旋转、本地存储
python3 tools/build_sensor_vdi.py
python3 tools/build_motion.py
bash tools/build_account_state.sh

# 原生辅助程序
bash tools/build_rmtfs.sh
bash tools/build_hexagonrpc.sh
bash tools/build_tinyalsa.sh
```

新编译结果位于 `code/port/out` 或 `/root/nabu-build/graphics/display-out`。替换镜像里的库时使用“写临时文件，再重命名”的方式；正在映射的 `.so` 不宜原位覆盖。

## 重新生成 EFI

在包根目录重新执行：

```powershell
.\prepare.ps1
```

EFI 由自编译内核、nabu 设备树和本机生成的调试公钥组装。
