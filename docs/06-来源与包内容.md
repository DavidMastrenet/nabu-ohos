# 来源与包内容

适配代码、差异补丁、预编译组件和 nabu 引导工具的来源如下。基础镜像通过本地路径提供。

| 组件 | 来源 |
| --- | --- |
| nabu Linux 6.17 | [M1DNYT3/sm8150-mainline-pmOS](https://github.com/M1DNYT3/sm8150-mainline-pmOS/tree/sm8150/6.17) |
| OHOS 内核接口参考 | [OpenHarmony kernel_linux_5.10](https://gitee.com/openharmony/kernel_linux_5.10) |
| DRM 显示适配基础 | [Oniro device_soc_oniro](https://github.com/eclipse-oniro-mirrors/device_soc_oniro) |
| Mesa OHOS 平台 | [OpenHarmony third_party_mesa3d](https://gitee.com/openharmony/third_party_mesa3d/tree/OpenHarmony-5.0-Release) |
| libdrm | [Mesa DRM 项目](https://gitlab.freedesktop.org/mesa/drm) |
| Hexagon RPC | [linux-msm/hexagonrpc](https://github.com/linux-msm/hexagonrpc) |
| QRTR、rmtfs、tqftpserv | [linux-msm](https://github.com/linux-msm) |
| BusyBox | [BusyBox](https://busybox.net/) |
| Dropbear | [Dropbear](https://github.com/mkj/dropbear) |
| TinyALSA | [TinyALSA](https://github.com/tinyalsa/tinyalsa) |
| nabu 临时 Recovery | [ArKT-7/twrp_device_xiaomi_nabu](https://github.com/ArKT-7/twrp_device_xiaomi_nabu/releases/tag/mod_linux) |
| UEFI、引导路径 | [Project Aloha](https://github.com/Project-Aloha/mu_aloha_platforms)、[nabu-dualboot-img](https://github.com/rodriguezst/nabu-dualboot-img) |
| rEFInd nabu | [refind-nabu](https://github.com/rodriguezst/refind-nabu) |
| Windows Python | [CPython 3.14.0](https://www.python.org/downloads/release/python-3140/)；许可证在 tools/python |
| SSH 客户端 | Windows OpenSSH；许可证在 tools/openssh |

内核、Mesa 和其余源码归档保留自身许可证。原始工程文件中的版权声明保留。

ADB/Fastboot 从 [Google Platform Tools](https://developer.android.com/tools/releases/platform-tools) 在使用者电脑下载。HDC 和 HarmonyOS 输入镜像从使用者自己安装的 DevEco SDK 使用。

引导镜像来自这次 nabu 适配所使用的实际 UEFI 引导文件；配置仅保留 OHOS 与 OHOS recovery。临时 Recovery 用于安装，不替换目标系统。
