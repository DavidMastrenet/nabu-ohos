# 需要自己提供的输入

## HarmonyOS 镜像

自行从 DevEco 获取 ARM64 平板模拟器镜像，版本 **7.0.0.107（SP8DEVC00E16R1P1log），API 26**。输入为本地 `system.img`、`vendor.img`、`sys_prod.img`。

适配副本在 `work/images/` 生成。补丁匹配原始指令和配置内容，其他版本需要重新适配。

## Android 硬件输入

`capture.ps1` 在擦除 Android 前提取。也可用 `import-hardware.py` 导入自己解包的固件。规范化后目录如下：

```text
work/hardware/
├── firmware/
│   ├── ath10k/WCN3990/hw1.0/
│   │   ├── board-2.bin
│   │   └── firmware-5.bin
│   ├── qcom/
│   │   ├── a630_sqe.fw
│   │   ├── a640_gmu.bin
│   │   └── sm8150/xiaomi/nabu/
│   │       ├── a640_zap.mbn
│   │       ├── adsp.mbn
│   │       ├── modem.mbn
│   │       ├── wlanmdsp.mbn
│   │       ├── slpi_nb.mbn
│   │       ├── cdsp.mbn
│   │       ├── venus.mbn
│   │       └── modemuw.jsn
│   ├── novatek/novatek_nt36523_fw.bin
│   ├── regulatory.db
│   └── regulatory.db.p7s
└── sensors/sensors/config/*.json
```

导入工具会将 MDT 分段组合成 ELF/MBN；WCN3990 可使用原生 `board-2.bin`，也可从本机 `bdwlan.bin` 生成匹配 nabu 的 board 容器。部分 ROM 的固件文件名不同，需要在本地按目录补齐。

`regulatory.db` 可来自自己安装的 `wireless-regdb` 包。若 Android 捕获未带这两份文件，在 WSL 里查找并复制到本地 hardware/firmware 目录：

```bash
find /lib/firmware /usr/lib/firmware -name 'regulatory.db*' 2>/dev/null
```

首次启动脚本从目标平板自身分区读取 modemst、fsg、fsc，保存到本地数据分区供 DSP 使用。

## 只在重新编译时需要的输入

同版本 Linux OHOS Clang、native sysroot 和原始 system 镜像。
