# 适配状态

基线：小米平板 5 nabu，HarmonyOS 7.0.0.107 SP8 ARM64 平板模拟器用户态，自编译 Linux 6.17。

| 功能 | 当前结果 |
| --- | --- |
| 图形界面、桌面、系统应用 | 真机可进入 |
| GPU | Adreno 640，Freedreno，OpenGL ES 3.2 |
| 触摸、亮度调节 | 已验证；唤醒依赖正确的 Novatek 固件 |
| Wi-Fi | 可扫描、连接及重连 |
| 电池 | 读取真实电量 |
| 存储 | 使用物理 userdata，能显示设备总容量 |
| 自动旋转 | 真实重力经 Motion HDI、MSDP、DMS 到桌面；已修复启动订阅顺序 |
| 外接键盘、鼠标 | USB HID 驱动自动加载，已被输入服务识别 |
| 扬声器 | S24_LE 播放清晰，系统通过 ALSA 转换；尾音仍有待进一步验证 |
| USB 调试 | OHOS SSH 2222、RAM 恢复 SSH 2223、HDC 8710 |
| 蓝牙 | 未完成，试验实现没有作为活动驱动部署 |
| 相机、麦克风、笔充电等 | 未完成验证 |
| 热重启 | 仍有内核早期启动失败，UFS 降频没有彻底消除 |

性能调整：补齐跨进程显示缓冲区元数据，修复每帧重复报错；渲染服务通过 `cpucore` 使用 CPU 4–7。设置滚动的中位帧间隔实测从约 16.7 ms 降到 8.3 ms，P95 从约 25 ms 降到 16.7 ms。CPU 与 GPU 继续动态调频。应用切换仍偶有长帧。

运行功能已在现有真机验证，Android 全新刷机待真机复现。
